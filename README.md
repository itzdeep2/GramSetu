# GramSetu — AI Rural Community Welfare & Grievance Matchmaker

> Built for **Build with AI: Code for Communities (Second Edition)** Hackathon on Hack2skill.

GramSetu is a multimodal-ready AI bridge engineered to assist rural and underserved citizens across India in navigating complex public welfare systems and civic grievance channels.

## 🎯 Problem Statement
Rural citizens often fail to receive benefits from relevant government schemes due to language barriers, lack of digital literacy, and complex bureaucratic procedures. GramSetu simplifies this: a citizen describes their condition in plain language, and the system matches them with active welfare schemes and immediate action steps.

## 🚀 Key Features
- **Conversational Scheme Matcher:** Understands natural rural language descriptions and maps them to schemes (PM-KISAN, PMFBY, Ayushman Bharat, PMAY).
- **Grievance Triage:** Categorizes civic infrastructure failures (broken water pumps, road potholes) and directs citizens to the exact nodal authority.
- **Multilingual Ready:** Adapts to queries in English, Hindi, and regional dialects.
- **Document Checklist:** Outlines exact paperwork required so citizens avoid repeated visits to government offices.

## 🛠️ Architecture & Tech Stack
- **AI Core:** Google Gemini 1.5 Flash via Google Generative AI API
- **Backend:** Netlify Serverless Functions (Node.js)
- **Frontend:** Lightweight HTML5, Tailwind CSS
- **Deployment:** Netlify Cloud
